    Technical Architecture

    Stack Overview
    Layer Technology Purpose Cost
    Frontend React.js Student + Company portals UI Free
    Database Firebase Firestore Store users, jobs, student profiles Free (tier)
    Authentication Firebase Auth Student/Company login Free
    AI Advisor Claude API (Sonnet 4.6) Major recommendations + matching Pay-as-you-go
    Hosting Netlify or Vercel Deploy frontend Free
    How it Works (User Flow)
    Student Portal:
    1. Student signs up → Firebase Auth creates account
    2. Student fills profiling form (interests, GPA, location)
    3. Form submitted → Claude API receives student data + major database
    4. Claude recommends top majors → Results displayed (salary, jobs, universities)
    5. Student can view more details, compare majors

    Company Portal:
    1. Company logs in → Firebase Auth
    2. Company posts job (title, major req, salary, skills)
    3. Job saved to Firestore database
    4. Company views dashboard → See matched students (filtering logic)
    5. Can contact/export student leads

    Matching Logic:
    When student profile is created, system automatically:
    - Matches their major interests to company job requirements
    - Filters by GPA, location preferences
    - Displays available jobs to student

    Risks & Mitigation

    Risk Impact Mitigation
    Data gathering is late 🔴 HIGH - Entire timeline slips Start TODAY. Person A + B dedicated full-time Week 1. Use proxy data if needed (UA/Lebanon salary data with disclosure).
    Claude API fails or is slow 🟡 MEDIUM - App doesn't work Use fallback: simple rule-based matching (if GPA > 3.5, recommend top majors). Still works, less impressive.
    Firebase has bugs 🟡 MEDIUM - Deployment delayed Have backup: deploy to simple JSON files + Node.js server (takes 1 day to pivot).
    Judges expect Arabic 🟡 MEDIUM - Loses points Skip Arabic in MVP (Week 3). Add in Week 4 if time (takes 1-2 days for i18n setup).
    Team member drops out 🔴 HIGH - Work redistributed Reduce scope: 3 universities instead of 6, 10 companies instead of 20. Still impressive with less data.
